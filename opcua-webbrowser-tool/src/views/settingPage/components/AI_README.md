# AI功能使用说明

## 功能概述

本项目已成功集成DeepSeek AI功能，为OPC UA Web浏览器工具添加了智能辅助功能。

## 主要功能

### 1. AI助手聊天
- **位置**: settingPage → AI助手标签页 → AI助手子标签
- **功能**: 与AI进行对话，获取OPC UA相关的技术支持和建议
- **特点**: 支持流式响应，实时显示AI回答过程

### 2. 代码分析
- **位置**: settingPage → AI助手标签页 → 代码分析子标签
- **功能**: 分析OPC UA相关代码，提供优化建议
- **支持语言**: JavaScript, TypeScript, Python, C#
- **特点**: 提供示例代码模板

### 3. 问题诊断
- **位置**: settingPage → AI助手标签页 → 问题诊断子标签
- **功能**: 诊断OPC UA连接和配置问题
- **特点**: 支持常见问题快速选择，环境信息收集

### 4. AI设置
- **位置**: settingPage → AI助手标签页 → AI设置子标签
- **功能**: 配置DeepSeek API密钥和AI参数
- **特点**: 支持会话管理，设置导出/导入

## 使用步骤

### 首次使用

1. **配置API密钥**
   - 打开settingPage
   - 点击"AI助手"标签页
   - 系统会自动弹出API配置对话框
   - 输入DeepSeek API密钥
   - 点击"确定"完成配置

2. **获取API密钥**
   - 访问 [DeepSeek平台](https://platform.deepseek.com/api_keys)
   - 注册账号并创建API密钥
   - 复制密钥到配置对话框

### 日常使用

1. **AI聊天**
   - 在AI助手标签页中直接输入问题
   - AI会根据当前OPC UA上下文提供专业回答
   - 支持快速操作按钮：分析配置、诊断问题、优化建议

2. **代码分析**
   - 粘贴需要分析的代码
   - 选择编程语言
   - 点击"分析代码"获取专业建议

3. **问题诊断**
   - 描述遇到的问题
   - 选择常见问题类型（可选）
   - 填写环境信息
   - 点击"开始诊断"获取解决方案

## 快速操作

在AI助手页面右下角有快速操作按钮：

- **🔍 分析当前节点**: 自动分析选中的OPC UA节点
- **⚠️ 诊断问题**: 快速诊断当前配置问题
- **💡 获取建议**: 基于当前配置获取优化建议

## 技术特性

### 上下文感知
- AI会自动获取当前选中的OPC UA节点信息
- 包含节点ID、数据类型、当前值等详细信息
- 提供更精准的分析和建议

### 会话管理
- 支持多个对话会话
- 自动保存对话历史
- 可切换和管理不同会话

### 流式响应
- 支持实时显示AI回答过程
- 提供更好的用户体验
- 可配置是否启用流式响应

## 配置说明

### API配置
- **API地址**: 默认 `https://api.deepseek.com`
- **模型**: 支持 `deepseek-chat` 和 `deepseek-coder`
- **API密钥**: 从DeepSeek平台获取

### AI参数
- **温度值**: 控制回答随机性 (0-1)
- **最大令牌数**: 控制回答长度 (100-4000)
- **流式响应**: 是否启用实时显示
- **自动保存上下文**: 是否自动保存对话历史

### 功能开关
- **代码分析**: 启用/禁用代码分析功能
- **问题诊断**: 启用/禁用问题诊断功能
- **智能建议**: 启用/禁用智能建议功能
- **自动分析**: 节点选择时自动分析
- **声音提示**: AI回答完成时播放提示音

## 注意事项

1. **API密钥安全**
   - 请妥善保管API密钥
   - 不要在代码中硬编码密钥
   - 定期更换密钥

2. **网络连接**
   - 需要稳定的网络连接
   - 确保能访问DeepSeek API服务

3. **使用限制**
   - 遵守DeepSeek API使用条款
   - 注意API调用频率限制
   - 合理使用AI功能

## 故障排除

### 常见问题

1. **API密钥验证失败**
   - 检查密钥是否正确
   - 确认密钥是否有效
   - 检查网络连接

2. **AI回答异常**
   - 检查API服务状态
   - 确认参数配置正确
   - 查看浏览器控制台错误信息

3. **功能无法使用**
   - 确认AI服务已初始化
   - 检查组件是否正确加载
   - 查看页面控制台错误

### 调试方法

1. **查看控制台**
   - 打开浏览器开发者工具
   - 查看Console标签页的错误信息

2. **检查网络**
   - 查看Network标签页的API请求
   - 确认请求状态和响应

3. **重置配置**
   - 在AI设置中点击"恢复默认"
   - 重新配置API密钥
