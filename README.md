# OPC UA WebAPI Kits
This project provides a complete set of development tools centered around OPC UA WebAPI, which can be used to build server-side and client applications based on UA WebAPI. It also includes a visualization tool for viewing and manipulating the address space of UA WebService. At present, instructional videos supporting this toolkit have been released on video platforms for developers to learn from.

## Components of the Toolkit

### 1. opcua-webservice-spring
An OPC UA Web service development toolkit built on the Java Spring framework. It supports converting heterogeneous data sources (such as SQL databases, OPC UA data, time-series data) and custom code logic into a standardized OPC UA information model, which can ultimately be accessed via the UA WebClient program.

### 2. opcua-webclient-ts
A UA WebClient module developed in TypeScript. It provides basic UA Web service invocation capabilities including Browse, Read, Write, and MethodCall, and can run in both browsers and Node.js environments.

### 3. opcua-webbrowser-tool
A visualization tool for the OPC UA WebService address space, with similar functionality to UaExpert.
Developers can access it directly through a browser from the official OPC Foundation website:
https://opcua-webbrowser-tool.opcfoundation.cn/

### 4. opcua-webservice-node
Functionally consistent with opcua-webservice-spring. It is currently under development and will be gradually improved in subsequent updates.
